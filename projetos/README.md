# Projetos - Programação para Web I

Este diretório contém os projetos Java propostos pelo professor.

## Estrutura

Cada projeto deve estar em sua própria pasta com:

- Código fonte organizado
- README.md descrevendo o projeto
- Arquivos de build (pom.xml ou build.gradle)

## Exemplo

```
projetos/
├── projeto01-hello-world/
│   ├── src/
│   ├── pom.xml
│   └── README.md
└── projeto02-calculadora/
    ├── src/
    ├── pom.xml
    └── README.md
```
